# نور المسلم — النسخة الكاملة

هذه النسخة تحافظ على ملفات الموقع الحالية وتضيف الخلفية اللازمة للعداد والدردشة.

## ما تمت إضافته
- عداد زوار حقيقي باستخدام Cloudflare Worker + D1.
- لوحة مسؤول خاصة على `/admin/`.
- تسجيل دخول للمسؤول بكلمة مرور محفوظة كـ Secret، وليس داخل الموقع.
- إجمالي الزوار، زوار اليوم، زوار الشهر، ومشاهدات الصفحات.
- دردشة/اقتراحات حقيقية محفوظة في D1.
- المسؤول يستطيع الرد، والزائر يرى الرد من نفس جهازه.
- لا يتم حفظ عنوان IP في قاعدة البيانات.
- لا يوجد عداد زوار في القائمة العامة.
- صور الأقصى والحرام والنبوي والتلاشي الموجود في النسخة السابقة محفوظة.

## مهم
هذه ليست نسخة Static Upload عادية؛ لأنها تحتوي Worker + D1. يجب نشرها كـ Cloudflare Worker مع Static Assets. Cloudflare توثق هذا الأسلوب كطريقة استضافة static assets مع Worker، ويمكن ربط D1 بالـ Worker. 

## إعداد مرة واحدة
### 1. تثبيت Wrangler على اللابتوب
```bash
npm install -g wrangler
wrangler login
```

### 2. من مجلد المشروع
```bash
wrangler deploy
```

في أول نشر، إذا طلب Wrangler إنشاء قاعدة D1، وافق.

### 3. تهيئة الجداول
بعد أن تظهر قاعدة `noor-almoslem-db`:
```bash
wrangler d1 execute noor-almoslem-db --remote --file=schema.sql
```

### 4. وضع كلمة مرور المسؤول
اختر كلمة مرور قوية:
```bash
wrangler secret put ADMIN_PASSWORD
```

ثم أدخل كلمة المرور عندما يطلبها.

### 5. وضع سر جلسة المسؤول
```bash
wrangler secret put ADMIN_SESSION_SECRET
```

استخدم سلسلة طويلة عشوائية، مثل 40+ حرفًا، ولا ترسلها لأحد.

### 6. فتح لوحة المسؤول
بعد النشر:
```text
https://اسم-موقعك.workers.dev/admin/
```
أو `/admin/` على نطاقك الخاص.

## إذا كانت قاعدة D1 أُنشئت مسبقًا
إذا لم ينشئ Wrangler القاعدة تلقائيًا، أنشئ D1 باسم `noor-almoslem-db` من Cloudflare ثم ضع `database_id` في `wrangler.jsonc` تحت `d1_databases` قبل `wrangler deploy`.

## لا تغيّر ملفات الموقع الأخرى
كل ملفات الموقع الحالية موجودة داخل `public/`. لا تحذفها ولا تنقلها. Worker هو الذي يضيف API والعداد ولوحة المسؤول فوق الموقع الموجود.
